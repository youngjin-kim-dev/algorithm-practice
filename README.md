## 풀이 방식
각 문제마다 두 개의 파일로 정리합니다.
- '.sql' 또는 '.py' - 정답 코드
- '.md' - 문제 요약, 접근 방법, 배운 점

파일명 규칙 : '문제번호_문제이름.확장자'
