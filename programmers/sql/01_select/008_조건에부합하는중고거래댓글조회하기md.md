# 조건에 부합하는 중고거래 댓글 조회하기

[프로그래머스 문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/164673)

## 문제 요약
USED_GOODS_BOARD (게시글)와 USED_GOODS_REPLY (댓글) 테이블에서
2022년 10월에 작성된 게시글의 댓글 정보 조회.
- 조회 컬럼: 게시글 제목, 게시글 ID, 댓글 ID, 댓글 작성자 ID, 댓글 내용, 댓글 작성일
- 댓글 작성일 오름차순, 같으면 게시글 제목 오름차순

## 접근 방법
1. 두 테이블 JOIN — BOARD_ID가 공통 키
2. WHERE로 게시글 작성일 2022년 10월 필터링
3. 댓글 작성일은 'YYYY-MM-DD' 포맷 (DATE_FORMAT)
4. ORDER BY 다중 컬럼 정렬

## 풀이
\`\`\`sql
SELECT A.TITLE, 
       A.BOARD_ID, 
       B.REPLY_ID, 
       B.WRITER_ID, 
       B.CONTENTS, 
       DATE_FORMAT(B.CREATED_DATE, '%Y-%m-%d') AS CREATED_DATE
FROM USED_GOODS_BOARD A
JOIN USED_GOODS_REPLY B ON A.BOARD_ID = B.BOARD_ID
WHERE YEAR(A.CREATED_DATE) = 2022 
  AND MONTH(A.CREATED_DATE) = 10
ORDER BY B.CREATED_DATE, A.TITLE;
\`\`\`

## 막힌 부분

### 1. DATE_FORMAT의 `%Y` vs `%y`
출력 포맷이 'YYYY-MM-DD' (예: 2022-10-15)인데 — 
연도 표기 코드를 헷갈림. 감으로 %Y 써서 맞췄으나 정확한 차이 학습 필요.

### 2. 함수 인자 안에 테이블 별칭
처음 작성 시 — `YEAR(CREATED_DATE)` 식으로 별칭 없이 작성하려 했으나
두 테이블 모두 CREATED_DATE 컬럼이 있어 — 어느 테이블 건지 명시 필요.

\`YEAR(A.CREATED_DATE)\` — 함수 안에서도 별칭 사용 가능.

## 배운 점

### DATE_FORMAT 연도 코드 — `%Y` vs `%y`
- `%Y` — **4자리 연도** (예: 2022)
- `%y` — **2자리 연도** (예: 22)

대문자 Y가 4자리, 소문자 y가 2자리. 헷갈리면 — **대문자가 더 큰 숫자(4자리)** 라고 외우기.

\`\`\`sql
DATE_FORMAT('2022-10-15', '%Y-%m-%d')   -- '2022-10-15'
DATE_FORMAT('2022-10-15', '%y-%m-%d')   -- '22-10-15'
\`\`\`

### 함수 안에서도 테이블 별칭 사용
두 테이블 모두 같은 컬럼명(CREATED_DATE)이 있을 때 — 함수 인자 안에서도 별칭 명시 필요.

\`\`\`sql
-- 두 테이블 모두 CREATED_DATE 있음
USED_GOODS_BOARD A
USED_GOODS_REPLY B

-- 함수 안에서도 별칭 필수
YEAR(A.CREATED_DATE)         -- 게시글 작성 연도
YEAR(B.CREATED_DATE)         -- 댓글 작성 연도
DATE_FORMAT(B.CREATED_DATE, '%Y-%m-%d')   -- 댓글 작성일 포맷팅
\`\`\`

별칭 없이 그냥 `YEAR(CREATED_DATE)`라고 쓰면 → "어느 테이블 거?"라는 모호성 에러.
**원칙: 두 테이블 JOIN 시 — 양쪽에 같은 컬럼명 있으면 어디든 별칭 필수.**

### 기존 학습과 연결
이번 문제는 — 본인이 학습한 여러 SQL 개념의 종합 활용:
- JOIN — 두 테이블 결합 (이전: 과일 아이스크림)
- 테이블 별칭 (A, B) — 같은 컬럼명 모호성 제거
- WHERE의 다중 조건 (AND)
- YEAR, MONTH — 날짜 추출 함수 (이전: 2021년 인문 도서)
- DATE_FORMAT — 날짜 포맷팅 (이전: 3월생 여성 회원)
- ORDER BY 다중 컬럼

## DATE_FORMAT 코드 정리 (참고)
| 코드 | 의미 | 예시 |
|---|---|---|
| %Y | 4자리 연도 | 2022 |
| %y | 2자리 연도 | 22 |
| %m | 2자리 월 | 10 |
| %d | 2자리 일 | 15 |
| %H | 24시간제 시 | 14 |
| %h | 12시간제 시 | 02 |
| %i | 분 | 30 |
| %s | 초 | 45 |

대문자/소문자 구분 — 형식이 다르므로 정확히 사용.
