# 3월에 태어난 여성 회원 목록 출력하기

[프로그래머스 문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/131120)

## 문제 요약
MEMBER_PROFILE에서 생일이 3월인 여성 회원 조회.
- 조회 컬럼: ID, 이름, 성별, 생년월일
- 전화번호 NULL 제외
- 회원ID 오름차순
- 생년월일은 'YYYY-MM-DD' 포맷

## 풀이
\`\`\`sql
SELECT MEMBER_ID, 
       MEMBER_NAME, 
       GENDER, 
       DATE_FORMAT(DATE_OF_BIRTH, '%Y-%m-%d') AS DATE_OF_BIRTH
FROM MEMBER_PROFILE
WHERE MONTH(DATE_OF_BIRTH) = 3
  AND GENDER = 'W'
  AND TLNO IS NOT NULL
ORDER BY MEMBER_ID;
\`\`\`

## 막힌 부분

### 1. 여성 조건 누락
처음에 GENDER = 'W' 조건을 빠뜨림. 문제에 "여성 회원"이라고 
명확히 적혀 있었는데 — 정독 부족으로 누락.

### 2. DATE 출력 포맷
본인 SQL:
\`\`\`sql
SELECT DATE_OF_BIRTH ...
\`\`\`
DATE 자료형의 기본 출력이 문제 요구(`1993-03-16`)와 달라서 실패.
DATE_FORMAT 함수로 명시적 포맷 지정 필요.

## 배운 점

### DATE_FORMAT 함수
\`\`\`sql
DATE_FORMAT(날짜컬럼, '형식')
\`\`\`

자주 쓰는 형식 코드:
- %Y — 4자리 연도 (1993)
- %m — 2자리 월 (03)
- %d — 2자리 일 (16)
- %H — 시, %i — 분, %s — 초

### YEAR/MONTH/DAY vs DATE_FORMAT
- YEAR(date), MONTH(date), DAY(date) — **숫자** 반환 (비교용)
- DATE_FORMAT(date, '형식') — **문자열** 반환 (출력용)

비교할 때는 YEAR/MONTH/DAY, 출력 포맷이 중요할 때는 DATE_FORMAT.

### 문제 정독의 중요성
SQL 자체는 맞았는데 — 조건 한 가지 누락으로 실패.
조건 여러 개 있는 문제는 — **모든 조건을 체크리스트화**해서 빠뜨리지 않기.

체크리스트 패턴:
- [ ] 어떤 컬럼 조회?
- [ ] 어떤 WHERE 조건들? (모두 나열)
- [ ] 정렬 기준?
- [ ] 출력 포맷 요구사항?
- [ ] NULL 처리 필요?

## 다른 풀이 — 부분 문자열로 처리 (권장 안 함)
\`\`\`sql
WHERE SUBSTRING(DATE_OF_BIRTH, 6, 2) = '03'
\`\`\`
가능은 하지만 — DATE 함수 활용이 표준이고 가독성 좋음.
