# 조건에 맞는 도서 리스트 출력하기

[프로그래머스 문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/144853)

## 문제 요약
BOOK 테이블에서 2021년에 출판된 '인문' 카테고리 도서의 
BOOK_ID와 PUBLISHED_DATE를 조회. 출판일 오름차순 정렬.

## 접근 방법
1. WHERE로 두 조건 필터링
   - 출판 연도가 2021인 행만 — YEAR() 함수로 연도 추출
   - 카테고리가 '인문'인 행만
2. SELECT로 BOOK_ID, PUBLISHED_DATE만 조회
3. ORDER BY로 출판일 오름차순 (ASC 기본값)

## 풀이
\`\`\`sql
SELECT BOOK_ID, PUBLISHED_DATE
FROM BOOK
WHERE YEAR(PUBLISHED_DATE) = 2021
  AND CATEGORY = '인문'
ORDER BY PUBLISHED_DATE;
\`\`\`

## 막힌 부분
처음 작성한 코드:
\`\`\`sql
SELECT BOOK_ID, PUBLISHED_DATE FROM BOOK
WHERE PUBLISHED_DATE YEAR = '2021' AND CATEGORY = '인문'
ORDER BY PUBLISHED_DATE
\`\`\`

날짜에서 연도만 추출하는 방법을 몰라 — 직관적으로 `PUBLISHED_DATE YEAR`로 작성했으나, 
SQL에서는 함수 형식 (`YEAR(컬럼)`)으로 사용해야 함.

## 배운 점
- 날짜에서 연도 추출 — `YEAR(컬럼)` 함수 사용
- YEAR() 결과는 숫자 → 비교 시 따옴표 없이 (`= 2021`)

## 날짜 함수 추가 학습
\`\`\`sql
YEAR(date)        -- 연도 추출 (예: 2021)
MONTH(date)       -- 월 추출 (예: 9)
DAY(date)         -- 일 추출 (예: 15)
HOUR(date)        -- 시 추출
MINUTE(date)      -- 분 추출
SECOND(date)      -- 초 추출
\`\`\`

활용 예시:
\`\`\`sql
-- 2021년 출판
WHERE YEAR(PUBLISHED_DATE) = 2021

-- 9월 출판
WHERE MONTH(PUBLISHED_DATE) = 9

-- 2021년 9월 출판
WHERE YEAR(PUBLISHED_DATE) = 2021 
  AND MONTH(PUBLISHED_DATE) = 9
\`\`\`

## 다른 풀이 방법 — BETWEEN
\`\`\`sql
SELECT BOOK_ID, PUBLISHED_DATE
FROM BOOK
WHERE PUBLISHED_DATE BETWEEN '2021-01-01' AND '2021-12-31'
  AND CATEGORY = '인문'
ORDER BY PUBLISHED_DATE;
\`\`\`

**YEAR() vs BETWEEN 비교**:
- YEAR() — 짧고 명확, 학습 단계에 좋음
- BETWEEN — 인덱스 활용 가능, 실무 성능 좋음 (대용량 데이터)

실무에서 데이터 많을 때는 BETWEEN이 권장되지만, 
지금 단계에서는 YEAR() 사용으로 함수 학습이 더 가치 있음.
