# 흉부외과 또는 일반외과 의사 목록 출력하기

[프로그래머스 문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/132203)

## 문제 요약
DOCTOR 테이블에서 진료과가 흉부외과(CS) 또는 일반외과(GS)인 의사 조회.
- 조회 컬럼: 이름, 의사ID, 진료과, 고용일자
- 고용일자 내림차순, 같으면 이름 오름차순

## 접근 방법
1. WHERE의 OR 연산자로 두 진료과 조건 처리
2. ORDER BY 다중 컬럼 정렬

## 풀이
\`\`\`sql
SELECT DR_NAME, DR_ID, MCDP_CD, HIRE_YMD
FROM DOCTOR
WHERE MCDP_CD = 'CS' OR MCDP_CD = 'GS'
ORDER BY HIRE_YMD DESC, DR_NAME;
\`\`\`

## 막힌 부분
한 번에 통과.

## 배운 점

## 다른 풀이 방법 — IN 연산자
\`\`\`sql
SELECT DR_NAME, DR_ID, MCDP_CD, HIRE_YMD
FROM DOCTOR
WHERE MCDP_CD IN ('CS', 'GS')
ORDER BY HIRE_YMD DESC, DR_NAME;
\`\`\`

**OR vs IN 비교**:
- OR — 조건이 적을 때 직관적
- IN — 조건이 많을 때 깔끔 (예: 5개 이상 값 비교)

여러 값 중 하나와 일치 비교하는 패턴은 — IN이 더 가독성 좋음.

\`\`\`sql
-- OR (값 5개)
WHERE col = 'A' OR col = 'B' OR col = 'C' OR col = 'D' OR col = 'E'

-- IN (같은 의미, 더 깔끔)
WHERE col IN ('A', 'B', 'C', 'D', 'E')
\`\`\`
