# 평균 일일 대여 요금 구하기

[프로그래머스 문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/151136)

## 문제 요약
CAR_RENTAL_COMPANY_CAR 테이블에서 자동차 종류가 'SUV'인 자동차의 평균 일일 대여 요금을 출력. 
소수 첫 번째 자리에서 반올림, 컬럼명 AVERAGE_FEE.

## 접근 방법
1. WHERE로 SUV만 필터링
2. AVG로 평균 계산
3. ROUND로 반올림
4. AS로 컬럼명 변경

## 풀이
\`\`\`sql
SELECT ROUND(AVG(DAILY_FEE)) AS AVERAGE_FEE
FROM CAR_RENTAL_COMPANY_CAR
WHERE CAR_TYPE = 'SUV';
\`\`\`

## 막힌 부분
처음에는 ROUND 없이 작성:
\`\`\`sql
SELECT AVG(DAILY_FEE) AS AVERAGE_FEE
FROM CAR_RENTAL_COMPANY_CAR
WHERE CAR_TYPE LIKE 'SUV';
\`\`\`

채점 데이터에서 소수가 나와 "소수 첫째 자리에서 반올림" 조건을 충족 못 시켜 실패.

ROUND 함수 추가 후 통과.

## 배운 점
- AVG 결과는 보통 소수가 나옴 — 문제에서 반올림 명시되어 있으면 ROUND 필수
- ROUND(숫자) — 소수 첫째 자리에서 반올림 (정수로)
- ROUND(숫자, N) — 소수 N+1째 자리에서 반올림 (소수 N자리까지 표시)
- 정확 일치 비교는 `=` 사용 (LIKE는 와일드카드 패턴 매칭용)
