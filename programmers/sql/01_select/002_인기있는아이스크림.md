# 인기있는 아이스크림

[프로그래머스 문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/133024)

## 문제 요약
FIRST_HALF 테이블에서 상반기에 판매된 아이스크림 맛(FLAVOR)을
- 총주문량(TOTAL_ORDER) 기준 내림차순
- 총주문량이 같으면 출하번호(SHIPMENT_ID) 기준 오름차순
으로 정렬하여 조회.

## 접근 방법
1. FLAVOR 컬럼만 SELECT
2. ORDER BY로 두 컬럼 동시 정렬
   - 첫 번째 기준: TOTAL_ORDER DESC (내림차순)
   - 두 번째 기준: SHIPMENT_ID (기본 ASC, 오름차순)

## 풀이
\`\`\`sql
SELECT FLAVOR
FROM FIRST_HALF
ORDER BY TOTAL_ORDER DESC, SHIPMENT_ID;
\`\`\`

## 막힌 부분
한 번에 통과.

## 배운 점
- ORDER BY에 여러 컬럼 작성 시 — 쉼표로 구분
- 첫 번째 컬럼 기준으로 정렬, 같은 값일 때 두 번째 컬럼 기준 정렬
- 각 컬럼마다 ASC/DESC 따로 지정 가능
- ASC는 기본값이라 생략 가능

## ORDER BY 추가 학습
\`\`\`sql
-- 단일 컬럼 정렬 (오름차순, 기본값)
ORDER BY column_name

-- 단일 컬럼 정렬 (내림차순)
ORDER BY column_name DESC

-- 여러 컬럼 정렬
ORDER BY col1 DESC, col2 ASC

-- 컬럼 인덱스로 정렬도 가능 (1번째 컬럼 기준)
ORDER BY 1
\`\`\`

여러 컬럼 정렬 시 — 첫 번째 기준으로 먼저 정렬, 그 안에서 같은 값이 있을 때만 두 번째 기준으로 정렬. 
마치 사전 순서처럼 (먼저 첫 글자, 같으면 두 번째 글자) 작동.
