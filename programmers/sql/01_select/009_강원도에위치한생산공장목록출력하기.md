# 강원도에 위치한 생산공장 목록 출력하기

[프로그래머스 문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/131112)

## 문제 요약
FOOD_FACTORY 테이블에서 강원도에 위치한 식품공장의 ID, 이름, 주소 조회.
- 공장 ID 오름차순 정렬

## 접근 방법
"강원도에 위치한" = 주소가 "강원도"로 시작
→ LIKE 사용

## 풀이
\`\`\`sql
SELECT FACTORY_ID, FACTORY_NAME, ADDRESS
FROM FOOD_FACTORY
WHERE ADDRESS LIKE '강원도%'
ORDER BY FACTORY_ID;
\`\`\`

## 막힌 부분
한 번에 통과.

## 배운 점

### LIKE 와일드카드의 진짜 용도
이전 학습에서 — LIKE를 정확 일치 비교(`LIKE 'SUV'`)로 잘못 사용한 경험.
이번엔 — **부분 일치 / 시작 일치**라는 LIKE의 진짜 용도로 사용.

\`\`\`sql
WHERE ADDRESS LIKE '강원도%'    -- 강원도로 시작
\`\`\`

이게 LIKE의 표준 용도. 정확 일치는 `=`.

### LIKE 와일드카드 정리
| 패턴 | 의미 | 예시 |
|---|---|---|
| `'A%'` | A로 시작 | `'강원도%'` |
| `'%A'` | A로 끝남 | `'%동'` |
| `'%A%'` | A를 포함 | `'%서울%'` |
| `'_A'` | 두 번째 글자가 A | `'_울'` |
| `'A_'` | A 다음 한 글자 있음 | `'서_'` |

- `%` — 0개 이상 모든 문자
- `_` — 정확히 한 글자

## 다른 풀이 방법

### LEFT 함수
\`\`\`sql
WHERE LEFT(ADDRESS, 3) = '강원도'
\`\`\`
왼쪽에서 N글자 추출 후 비교.

### SUBSTRING 함수
\`\`\`sql
WHERE SUBSTRING(ADDRESS, 1, 3) = '강원도'
\`\`\`
시작 위치부터 N글자 추출.

**LIKE vs 함수 비교**:
- LIKE — 표준, 가독성 좋음
- 함수들 — 가능하지만 복잡

가장 표준은 LIKE. 함수는 더 복잡한 패턴 매칭에 사용.
