# 12세 이하인 여자 환자 목록 출력하기

[프로그래머스 문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/132201)

## 문제 요약
PATIENT 테이블에서 12세 이하 여자환자(GEND_CD = 'W')의 정보를 조회.
- 조회 컬럼: 환자이름, 환자번호, 성별코드, 나이, 전화번호
- 전화번호(TLNO)가 NULL이면 'NONE'으로 출력
- 나이 내림차순, 같으면 환자이름 오름차순

## 테이블 정보
| 컬럼 | 자료형 | Nullable | 의미 |
|---|---|---|---|
| PT_NO | VARCHAR(10) | FALSE | 환자번호 |
| PT_NAME | VARCHAR(20) | FALSE | 환자이름 |
| GEND_CD | VARCHAR(1) | FALSE | 성별코드 |
| AGE | INTEGER | FALSE | 나이 |
| TLNO | VARCHAR(50) | **TRUE** | 전화번호 (NULL 가능) |

TLNO가 Nullable: TRUE → NULL 처리 필요 신호.

## 접근 방법
1. SELECT로 5개 컬럼 조회
2. WHERE로 두 조건 필터링 (AGE <= 12, GEND_CD = 'W')
3. TLNO가 NULL일 때 'NONE'으로 출력 → IFNULL 함수
4. ORDER BY로 다중 컬럼 정렬 (나이 DESC, 이름 ASC)

## 풀이
\`\`\`sql
SELECT PT_NAME, PT_NO, GEND_CD, AGE, IFNULL(TLNO, 'NONE') AS TLNO
FROM PATIENT
WHERE AGE <= 12
  AND GEND_CD = 'W'
ORDER BY AGE DESC, PT_NAME;
\`\`\`

## 막힌 부분
WHERE, ORDER BY 등 다른 부분은 풀 수 있었는데 
**NULL 처리 함수를 모름**. IFNULL, COALESCE 함수 처음 학습.

## 배운 점

### IFNULL 함수
\`\`\`sql
IFNULL(컬럼, 대체값)
\`\`\`
- 컬럼이 NULL이면 → 대체값 반환
- 컬럼이 NULL이 아니면 → 원래 값 반환
- MySQL 전용 함수

### AS로 컬럼명 유지
\`\`\`sql
IFNULL(TLNO, 'NONE') AS TLNO
\`\`\`
함수 결과는 컬럼명이 함수 표현식 그대로 나옴.
`AS TLNO`로 원래 컬럼명 유지.

### NULL의 특성
- NULL은 "값 없음" 상태
- `=` 비교 불가능 → `IS NULL`, `IS NOT NULL`만 사용
\`\`\`sql
WHERE TLNO = NULL          -- 작동 안 함
WHERE TLNO IS NULL         -- 작동
WHERE TLNO IS NOT NULL     -- 작동
\`\`\`

### Nullable 정보의 의미
테이블 정보에서 Nullable: TRUE인 컬럼 → NULL 처리 필요할 수 있음.
문제 풀기 전 자료형·Nullable 확인하면 어떤 함수 필요한지 미리 알 수 있음.

## 다른 풀이 방법

### COALESCE 함수 (표준 SQL)
\`\`\`sql
SELECT PT_NAME, PT_NO, GEND_CD, AGE, COALESCE(TLNO, 'NONE') AS TLNO
FROM PATIENT
WHERE AGE <= 12 AND GEND_CD = 'W'
ORDER BY AGE DESC, PT_NAME;
\`\`\`

**IFNULL vs COALESCE**:
- IFNULL — MySQL 전용, 인자 2개
- COALESCE — 표준 SQL (모든 DB), 인자 여러 개 가능
- 실무에선 COALESCE가 표준

COALESCE 다중 인자 활용:
\`\`\`sql
COALESCE(컬럼1, 컬럼2, '기본값')
-- 컬럼1이 NULL이면 컬럼2, 그것도 NULL이면 '기본값'
\`\`\`

### CASE WHEN (가장 명시적)
\`\`\`sql
CASE 
    WHEN TLNO IS NULL THEN 'NONE'
    ELSE TLNO
END AS TLNO
\`\`\`
복잡한 조건일 때 사용. 단순 NULL 처리는 IFNULL/COALESCE가 깔끔.
