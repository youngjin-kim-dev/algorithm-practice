# 문자열 반복해서 출력하기

[프로그래머스 문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/181950)

## 문제 요약
문자열 str과 정수 n을 입력받아 — str을 n번 이어 붙인 문자열 출력.

**입력**: `string 5`
**출력**: `stringstringstringstringstring`

## 풀이
\`\`\`python
str, n = input().strip().split(' ')
n = int(n)

print(str * n)
\`\`\`

## 막힌 부분

### 1차 시도 — C/Java 스타일 for문
\`\`\`python
for(i in range(5)):
    print(n)
\`\`\`

문제 세 가지:
1. **Python의 for 문법 잘못** — 괄호 없어야 함
2. **range(5) 고정값** — 입력값 n에 따라 가변이어야 함
3. **print(n)** — 숫자 출력 (문자열 str을 출력해야 함)

Python 정답:
\`\`\`python
for i in range(n):
    print(str)
\`\`\`

### 출력 형식 확인 — 줄바꿈 없이 이어 붙이기
for문 풀이는 — 줄마다 한 번씩 출력 (`string\\nstring\\n...`).
기대 출력 — 한 줄로 이어진 `stringstringstring...`.

→ **`*` 연산자**로 문자열 반복이 더 간단.

## 배운 점

### Python의 for문 문법
\`\`\`python
for 변수 in 반복가능:
    실행할 코드
\`\`\`

**핵심 규칙**:
- 괄호 `()` **없음**
- 콜론(`:`) 필수
- 들여쓰기로 블록 구분

\`\`\`python
# Python (정답)
for i in range(5):
    print(i)

# C/Java 스타일 (잘못)
for (i in range(5)):    # 에러
\`\`\`

### 문자열 곱셈 — `*` 연산자
\`\`\`python
"abc" * 3    # "abcabcabc" (3번 반복)
"a" * 5      # "aaaaa"
"ab" * 0     # "" (빈 문자열)
\`\`\`

문자열을 숫자만큼 — **이어 붙여 반복**.

### 자료형별 연산자 의미 (정리)
이번 학습 — `*` 연산자도 자료형별로 의미 다름:

| 연산자 | 숫자 | 문자열 |
|---|---|---|
| `+` | 덧셈 (3 + 5 = 8) | 연결 ("a" + "b" = "ab") |
| `*` | 곱셈 (3 * 5 = 15) | 반복 ("a" * 3 = "aaa") |
| `-` | 뺄셈 | 에러 |
| `/` | 나눗셈 | 에러 |

`+`와 `*`는 — 문자열에서도 의미 있게 사용 가능. 빼기·나눗셈은 불가능.

### `range()` — 반복 횟수 제어
\`\`\`python
range(5)    # 0, 1, 2, 3, 4 (5번)
range(n)    # 입력값에 따라 가변
\`\`\`

고정값 vs 가변값 — 상황에 맞게 선택.

### Python의 간결함
\`\`\`python
# 방법 1 — for문 (긴 코드)
for i in range(n):
    print(str, end='')    # end='' 안 하면 줄바꿈

# 방법 2 — 문자열 곱셈 (한 줄)
print(str * n)
\`\`\`

같은 결과 — Python은 더 짧은 방법 제공.
이게 — "Pythonic"한 코드의 특징.

## 입출력 흐름
입력: `string 5`

\`\`\`
str = "string", n = "5"
n = int("5") = 5
str * n = "string" * 5 = "stringstringstringstringstring"

출력: stringstringstringstringstring
\`\`\`

## `str` 변수명 주의 (참고)
`str`은 — Python의 **내장 함수**(문자열 변환).
\`\`\`python
str(123)    # "123" (숫자 → 문자열)
\`\`\`

변수명으로 `str` 사용하면 — 내장 함수 가려서 그 후로 `str()` 사용 불가.
이번 문제는 — 변수명을 `str`로 명명해서 그대로 사용. 실무에선 `s` 같은 다른 이름 권장.
