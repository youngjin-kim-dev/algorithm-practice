# 대소문자 바꿔서 출력하기

[프로그래머스 문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/181949)

## 문제 요약
알파벳 문자열을 받아 — 대문자는 소문자로, 소문자는 대문자로 변환 후 출력.

**입력**: `aBcDeFg`
**출력**: `AbCdEfG`

## 풀이
\`\`\`python
str = input()

print(str.swapcase())
\`\`\`

## 막힌 부분
문법 자체를 모름. "메모리 주소로 접근해야 하나?" 같은 C 스타일 사고로 접근했으나 — 
Python은 **이미 만들어진 메소드**로 한 줄 해결.

## 배운 점

### `swapcase()` 메소드 — 대소문자 뒤집기
\`\`\`python
"aBc".swapcase()    # "AbC"
"Hello".swapcase()  # "hELLO"
\`\`\`

대문자 ↔ 소문자 한 번에 변환.

### Python의 주요 문자열 메소드
| 메소드 | 동작 |
|---|---|
| `.upper()` | 모두 대문자 |
| `.lower()` | 모두 소문자 |
| `.swapcase()` | 대소문자 뒤집기 |
| `.capitalize()` | 첫 글자만 대문자 |
| `.title()` | 단어마다 첫 글자 대문자 |
| `.isupper()` | 대문자인지 (True/False) |
| `.islower()` | 소문자인지 (True/False) |

### 직접 구현하는 방법 (참고)
swapcase()를 모르거나 직접 만들고 싶다면:
\`\`\`python
str = input()
result = ""

for char in str:
    if char.isupper():
        result += char.lower()
    elif char.islower():
        result += char.upper()

print(result)
\`\`\`

**사용 메소드**:
- `.isupper()`, `.islower()` — 대소문자 판별
- `.lower()`, `.upper()` — 변환

다만 — `swapcase()`가 훨씬 짧고 표준.

### Pythonic 사고법
"이걸 하는 메소드가 이미 있을까?" 먼저 생각.

| 작업 | Python 메소드 |
|---|---|
| 대소문자 변환 | upper, lower, swapcase |
| 분리 | split |
| 양 끝 공백 제거 | strip |
| 위치 찾기 | index, find |
| 치환 | replace |
| 정렬 채우기 | ljust, rjust |
| 반복 | * 연산자 |

Python은 — 메소드 풍부해서 직접 구현 거의 안 함.
이게 — "Pythonic" 코드의 핵심.

### 언어별 사고 차이
**C 스타일** (메모리 주소·ASCII 코드 직접):
\`\`\`c
if (char >= 'a' && char <= 'z')
    char = char - 32;    // 소문자 → 대문자
\`\`\`

**Python 스타일** (메소드로 추상화):
\`\`\`python
char.upper()
\`\`\`

Python은 — **"어떻게"보다 "무엇을"** 표현하는 데 집중.
의문이 들 때마다 — "이 작업하는 메소드 있을까?" 검색.
