# a와 b 출력하기

[프로그래머스 문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/181951)

## 문제 요약
정수 a와 b를 입력받아 `a = N`, `b = N` 형식으로 두 줄 출력.

**입력**: `4 5`
**출력**:
\`\`\`
a = 4
b = 5
\`\`\`

기본 세팅:
\`\`\`python
a, b = map(int, input().strip().split(' '))
print(a + b)
\`\`\`

`print(a + b)` 부분을 출력 형식에 맞게 수정.

## 풀이
\`\`\`python
a, b = map(int, input().strip().split(' '))

print(f'a = {a}')
print(f'b = {b}')
\`\`\`

## 막힌 부분

### 1차 시도 — `,`로 인자 여러 개
\`\`\`python
print(f'a =', a, '\\n', f'b =', b)
\`\`\`

실패 출력:
\`\`\`
a = 4 
 b = 5
\`\`\`

원인: `print()`에 `,`로 인자 구분하면 — **자동으로 공백 추가**.
- `a` 다음에 공백
- `\n` 양 옆에 공백
- `b` 앞에 공백

기대 출력과 공백 위치가 달라서 실패.

### 핵심 깨달음
- `print()`의 `,`는 자동 공백 추가
- 정확한 출력 형식 맞추려면 — **하나의 문자열로** 만들어 print
- f-string으로 — 변수와 글자 깔끔하게 연결

## 배운 점

### `f-string` — 문자열 포매팅
\`\`\`python
print(f'a = {a}')    # "a = 4"
\`\`\`

**규칙**:
1. 문자열 앞에 `f` 붙임
2. `{변수}` — 그 자리에 변수 값으로 대체
3. `{}` 없으면 그냥 글자

### `f` 유무 차이
\`\`\`python
a = 4

print('a = {a}')     # "a = {a}" (그냥 글자)
print(f'a = {a}')    # "a = 4" (변수 값)
\`\`\`

`f`가 — "이 문자열은 변수 처리해줘" 신호.

### f-string의 다양한 활용
\`\`\`python
name = "영진"
age = 23

print(f'{name}은 {age}살')          # "영진은 23살"
print(f'내년엔 {age + 1}살')         # 수식도 OK
print(f'첫 글자: {name[0]}')        # 인덱스도 OK
\`\`\`

`{}` 안에 — 변수, 수식, 메소드 호출 다 가능.

### `print()`의 자동 공백 문제
\`\`\`python
print('a', 'b', 'c')      # "a b c" (자동 공백)
print('a' + 'b' + 'c')    # "abc" (공백 없음)
\`\`\`

`,`로 인자 구분 시 — 자동 공백. 출력 형식 정확히 맞추려면 주의.

### 다른 출력 방법들 (참고)

**방법 1 — 두 줄 print (이번 풀이)**
\`\`\`python
print(f'a = {a}')
print(f'b = {b}')
\`\`\`

**방법 2 — f-string에 \\n 직접 포함**
\`\`\`python
print(f'a = {a}\\nb = {b}')
\`\`\`

**방법 3 — `+` 연산자**
\`\`\`python
print('a = ' + str(a))    # str() 변환 필요
\`\`\`

**방법 4 — `sep` 매개변수**
\`\`\`python
print('a =', a, sep='')   # 자동 공백 제거
\`\`\`

**비교**:
| 방법 | 가독성 | 자료형 변환 |
|---|---|---|
| f-string | 최고 | 자동 |
| + 연결 | 보통 | 수동 (str()) |
| , 구분 | 짧음 | 자동 (공백 문제) |

**f-string이 표준** (Python 3.6+).

## 기본 세팅 코드 분석

\`\`\`python
a, b = map(int, input().strip().split(' '))
\`\`\`

분해:
1. `input()` → `"4 5"` 입력 받기
2. `.strip()` → 양 끝 공백 제거 → `"4 5"`
3. `.split(' ')` → 공백 기준 분리 → `["4", "5"]`
4. `map(int, ...)` → 각 원소를 정수로 → 4, 5
5. `a, b = ...` → a=4, b=5 동시 할당

### `map()` 함수
\`\`\`python
map(함수, 반복가능)    # 각 원소에 함수 적용
\`\`\`

### `strip()` 메소드
양 끝 공백·줄바꿈 제거.
\`\`\`python
"  hello  ".strip()    # "hello"
\`\`\`

### `split()` vs `split(' ')`
\`\`\`python
"3 5".split(' ')       # ["3", "5"]
"3   5".split(' ')      # ["3", "", "", "5"] (공백 여러 개면 빈 문자열)
"3   5".split()         # ["3", "5"] (인자 없이는 모든 공백 처리, 더 안전)
\`\`\`

### 다중 할당
\`\`\`python
a, b = map(int, ...)    # 두 변수 동시 할당
\`\`\`
