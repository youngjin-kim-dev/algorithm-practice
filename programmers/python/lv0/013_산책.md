## 문제 요약
2차원 좌표평면에서 동/서/남/북 방향으로 1m씩 이동.
- N: 북쪽 +1, S: 남쪽 +1 (북쪽 -1)
- E: 동쪽 +1, W: 서쪽 +1 (동쪽 -1)

route 문자열에 따라 이동한 후 — `[동쪽 거리, 북쪽 거리]` 반환.

## 풀이
\`\`\`python
def solution(route):
    east = 0
    north = 0
    for i in route:
        if i == "N":
            north += 1
        elif i == "S":
            north -= 1
        elif i == "E":
            east += 1
        elif i == "W":
            east -= 1
    return [east, north]
\`\`\`

**빈칸 답**:
- 8번줄: `north -= 1` (남쪽 = 북쪽 -1)
- 10번줄: `east += 1` (동쪽 +1)
- 11번줄: `"W"` (서쪽 케이스)
- 12번줄: `east -= 1` (서쪽 = 동쪽 -1)

## 배운 점

### 좌표 표현 — 음수로 반대 방향
2차원 좌표에서 — 4방향을 2개 변수로만 처리:
- 북쪽 +1, 남쪽 -1 (north 변수 하나)
- 동쪽 +1, 서쪽 -1 (east 변수 하나)

**반대 방향을 음수로 처리하는 패턴** — 좌표·벡터 계산의 표준.
변수 4개 안 쓰고 2개로 충분.

### 문자열 순회 — `for i in route`
문자열도 리스트처럼 — for문으로 한 글자씩 순회 가능.
\`\`\`python
for i in "NSEW":
    print(i)    # N, S, E, W 순서대로
\`\`\`

이전 학습한 — 리스트 순회 패턴이 문자열에도 동일하게 적용됨.
### 리스트로 반환
함수가 — 두 값을 동시에 반환하려면 리스트(또는 튜플)로:
\`\`\`python
return [east, north]
\`\`\`
