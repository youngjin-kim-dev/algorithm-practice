# 빈칸 채우기 — 출력

[프로그래머스 문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/250133)

## 문제 요약
빈칸 3개를 채워서 다음 출력이 나오도록:
\`\`\`
Spring is beginning
13
310
\`\`\`

## 풀이
\`\`\`python
string_msg = "Spring is beginning"
int_val = 3
string_val = "3"

print(string_msg)
print(int_val + 10)         # 3 + 10 = 13 (숫자 덧셈)
print(string_val + "10")    # "3" + "10" = "310" (문자열 연결)
\`\`\`

## 막힌 부분
세 번째 빈칸(`string_val`)에서 막힘.

### 1차 시도 — `string_val = "300"`
출력 "310"을 보고 — "300에 10 더하면 310" 사고로 작성:
\`\`\`python
string_val = "300"
print(string_val + "10")    # "30010"
\`\`\`
결과 "30010" — "300"이라는 문자열에 "10"이 그대로 이어 붙음. 의도와 다름.

### 2차 시도 — 빼기로 생각
"310"에서 "10"을 빼면 처음 값으로 생각해서:
\`\`\`python
"310" - "10"    # 의도
\`\`\`
다만 — 문자열은 빼기 불가능. TypeError 발생.

### 정답 — `string_val = "3"`
"3" 옆에 "10" 이어 붙으면 "310". 단순 연결 사고.

## 배운 점

### `+`의 자료형별 의미
\`\`\`python
3 + 10           # 13 (숫자 덧셈, 산술 연산)
"3" + "10"       # "310" (문자열 연결)
3 + "10"         # 에러! (자료형 불일치)
\`\`\`

같은 `+` 기호 — 자료형에 따라 동작 다름.
- 숫자 + 숫자 = 산술 덧셈
- 문자열 + 문자열 = 연결 (concatenation)
- 숫자 + 문자열 = TypeError

### 따옴표가 자료형 신호
- `10` — 숫자
- `"10"` — 문자열 (따옴표로 감쌈)

따옴표 보면 문자열, 없으면 숫자. 이 시각적 차이가 자료형 구분.

### 문자열에 가능한 연산
\`\`\`python
"abc" + "def"    # "abcdef" (연결)
"abc" * 3        # "abcabcabc" (반복)
"abc" - "a"      # 에러! (빼기 불가능)
"abc" / "a"      # 에러! (나눗셈 불가능)
\`\`\`

문자열 — `+`(연결)와 `*`(반복) 가능. 빼기·나눗셈 불가능.

### 형변환으로 자료형 통합
숫자와 문자열 합치고 싶을 때 — 변환 필요:
\`\`\`python
str(3) + "10"    # "310" (숫자 → 문자열 후 연결)
3 + int("10")    # 13 (문자열 → 숫자 후 덧셈)
\`\`\`

이전 학습한 `str()`, `int()` 함수가 여기서 활용됨.

## 자료형의 중요성
문제를 풀 때 — **각 값의 자료형이 무엇인지 먼저 인식**하는 게 핵심.
- `print(int_val + 10)` — `10`이 숫자 → 숫자 덧셈
- `print(string_val + "10")` — `"10"`이 문자열 → 문자열 연결

`+` 옆에 따옴표 있는지 없는지가 — 어떤 연산인지 결정.
