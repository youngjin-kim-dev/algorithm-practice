# 디버깅 - 피타고라스의 정리

[프로그래머스 문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/250132)

## 문제 요약
직각삼각형의 한 변 a와 빗변 c가 주어질 때, 다른 한 변의 **길이의 제곱**(b_square) 출력.
피타고라스: a² + b² = c² → b² = c² - a²

## 원본 코드 (버그 있음)
\`\`\`python
b_square = c - a
\`\`\`
단순 뺄셈 — 제곱 빠짐.

## 풀이
\`\`\`python
b_square = c**2 - a**2
\`\`\`

## 막힌 부분

### 1차 시도 — sqrt로 b 길이 구하려 함
\`\`\`python
b_square = sqrt(c*c - a*a)
\`\`\`

문제 두 가지:
1. **문제 정독 부족** — "다른 한 변의 길이의 **제곱**"인데 — "길이" 부분만 보고 b 자체를 구하려 함. 출력 예시(16, 19)도 — 4², √19²의 제곱값.
2. **`sqrt` import 안 함** — `sqrt`는 Python 기본 함수 아니라 `math` 모듈에 있음. `import math` 후 `math.sqrt()` 사용해야 함.

### 정답 — 제곱근 안 씌우기
문제는 — b의 **제곱**값 구하기. sqrt 자체가 필요 없음.
- a² = a**2 (또는 a*a)
- 출력: c**2 - a**2

## 배운 점

### Python 거듭제곱 `**`
\`\`\`python
2 ** 3      # 8 (2의 3제곱)
5 ** 2      # 25 (5의 제곱)
9 ** 0.5    # 3.0 (제곱근)
\`\`\`

`**` (별 두 개) = 거듭제곱 연산자. Python 고유.
- 다른 언어(C, Java)는 `Math.pow()` 함수 사용
- Python은 연산자 `**`로 간결

### 제곱근 구하는 두 가지 방법
\`\`\`python
import math
math.sqrt(16)    # 4.0

16 ** 0.5        # 4.0 (import 불필요)
\`\`\`

`**`로 0.5승 = 제곱근. 더 간결.

### 모듈 import의 의미
\`\`\`python
sqrt(16)         # NameError (모듈 import 안 함)
import math
math.sqrt(16)    # 4.0
\`\`\`

`sqrt`는 Python 기본 함수 아님 → `math` 모듈에 정의되어 있음.
사용 전 `import math` 필요. 그 후 `math.sqrt(...)` 형태로 호출.

### 문제 정독의 중요성
"제곱" 한 단어를 놓치고 — sqrt 사용해서 b 자체를 구하려 했음.
한 단어 차이로 — 답이 4 vs 16으로 완전히 달라짐.

천천히 읽고 — 출력 예시까지 확인하는 습관 필요.

### 등호 `=`의 의미
\`\`\`python
b_square ** 2 = ...    # 에러! 등호 좌변에 표현식 안 됨
b_square = ...         # OK (변수에 대입)
\`\`\`

`=`는 — "오른쪽을 계산해서 왼쪽 변수에 저장". 좌변은 변수명만 가능.

이건 수학의 등호(`=`)와 의미 다름:
- 수학: `b² = c² - a²` (좌우 같다)
- 코드: `b_square = c**2 - a**2` (오른쪽을 왼쪽에 대입)

## 출력 예시 검증
- a=3, c=5 → 25 - 9 = **16** ✓
- a=9, c=10 → 100 - 81 = **19** ✓
