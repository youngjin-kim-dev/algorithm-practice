# 디버깅 — 닉네임 규칙

[프로그래머스 문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/340200)

## 문제 요약
사용할 수 없는 닉네임(l, w, O, W 포함)을 규칙에 따라 변환.
- l → I, w → vv, W → VV, O → 0
- 길이 4 미만이면 'o' 붙여서 4로
- 길이 8 초과면 8자까지만

1줄만 수정해서 버그 고치는 디버깅 문제.

## 원본 코드 (버그 있음)
\`\`\`python
if len(answer) < 3:
    answer += "o"
\`\`\`

문제: 
- 조건 `< 3` 잘못 (문제는 `< 4`)
- if문은 한 번만 실행 — 길이 1짜리 닉네임이면 한 번 추가해도 길이 2~3, 여전히 4 미만

## 풀이
\`\`\`python
while len(answer) < 4:
    answer += "o"
\`\`\`

`if`를 `while`로 변경. 길이 4 될 때까지 반복적으로 'o' 추가.

## 막힌 부분
한 번에 통과. 다만 — Python에서 while을 일반적으로 자주 쓰는지 의문.

## 배운 점

### `if` vs `while` 차이
- `if 조건:` — 조건 **한 번** 체크 → 실행 또는 안 실행
- `while 조건:` — 조건 **반복적으로** 체크 → 만족 동안 계속 실행

이번 문제처럼 — "조건 만족할 때까지" 반복해야 하는 경우 `while` 사용.

### Python의 while 사용 시점

**while이 표준인 경우**:
- 끝나는 시점이 동적 (몇 번 반복할지 모름)
- 조건 만족할 때까지 반복
- 무한 루프 + break 패턴

**for가 더 표준인 경우**:
- 횟수가 정해진 반복 (`for i in range(N)`)
- 컬렉션 순회 (`for item in list`)

이번 문제는 — "길이가 4 될 때까지"로 동적이라 while 적합.

### 한 줄 수정의 의미
`if` → `while`로 키워드 한 단어 바꾸는 것도 한 줄 수정.
디버깅에서 — 구조 자체를 바꿀 필요 없이 키워드만 변경하는 패턴.

## 다른 풀이 방법 — Python 메소드 활용

### `ljust()` 메소드
\`\`\`python
answer = answer.ljust(4, "o")[:8]
\`\`\`

`ljust(길이, 문자)` — 지정 길이까지 왼쪽 정렬, 오른쪽을 문자로 채움.
- `"AB".ljust(4, "o")` → `"ABoo"`
- `"ABCDE".ljust(4, "o")` → `"ABCDE"` (이미 충분하면 그대로)

뒤에 `[:8]` — 8자 초과 시 자르기.

가장 Python스러운 한 줄 풀이. 다만 — 빈칸 채우기/디버깅 문제에선 
원본 구조 유지가 의도라 while 사용이 맞음.
