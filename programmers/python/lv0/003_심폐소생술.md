# 빈칸 채우기 — 심폐소생술

[프로그래머스 문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/340203)

## 문제 요약
무작위 순서로 담긴 심폐소생술 단계 리스트 cpr이 주어질 때,
각 단계가 정상 순서에서 몇 번째인지 순서대로 반환.

**입력 예시**: `["call", "respiration", "repeat", "check", "pressure"]`
**출력 예시**: `[2, 4, 5, 1, 3]`

## 풀이
\`\`\`python
def solution(cpr):
    answer = []
    basic_order = ["check", "call", "pressure", "respiration", "repeat"]
    
    for action in cpr:
        for i in range(len(basic_order)):
            if action == basic_order[i]:
                answer.append(i + 1)
    return answer
\`\`\`

## 막힌 부분

### 1차 시도 — 두 번째 빈칸에 `basic_order`
\`\`\`python
for i in basic_order:
    if action == basic_order[i]:
\`\`\`
에러:
\`\`\`
TypeError: list indices must be integers or slices, not str
\`\`\`

원인: `for i in basic_order:` → i가 문자열("check", "call" 등)이 됨.
그 후 `basic_order[i]` (문자열로 인덱스 접근) → 에러.

해결: `for i in range(len(basic_order)):` → i가 정수(0~4)가 됨.

### 2차 시도 — 세 번째 빈칸에 `i`
\`\`\`python
answer.append(i)
\`\`\`

결과:
- 입력: `["call", "respiration", "repeat", "check", "pressure"]`
- 기대: `[2, 4, 5, 1, 3]`
- 실제: `[1, 3, 4, 0, 2]`

원인: Python 인덱스는 0부터 시작 (0, 1, 2, 3, 4).
문제는 사람이 읽는 순서 (1, 2, 3, 4, 5).

해결: `answer.append(i + 1)` — 인덱스에 +1.

## 배운 점

### 1. 리스트 인덱스는 정수만 가능
\`\`\`python
basic_order[0]      # OK (정수)
basic_order["a"]    # 에러 (문자열)
\`\`\`

### 2. for문의 두 가지 패턴

**원소 자체 순회**:
\`\`\`python
for item in 리스트:
    # item은 리스트의 각 원소 (값 자체)
\`\`\`

**인덱스로 순회**:
\`\`\`python
for i in range(len(리스트)):
    # i는 0부터 len-1까지의 정수
    # 리스트[i]로 원소 접근
\`\`\`

### 3. `range(len(리스트))` 패턴
인덱스 필요할 때 자주 쓰는 표준 패턴.
\`\`\`python
basic_order = ["check", "call", "pressure", "respiration", "repeat"]
range(len(basic_order))    # range(5) → 0, 1, 2, 3, 4
\`\`\`

### 4. Python 인덱스 vs 사람의 순서
- Python 인덱스: 0부터 시작 (0, 1, 2, 3, 4)
- 사람이 세는 순서: 1부터 시작 (1번째, 2번째, 3번째...)

문제에서 "몇 번째"를 요구하면 — 인덱스에 `+ 1` 필요.

이번 시행착오 — Python 0부터 시작하는 인덱스를 잠깐 잊고 `i` 그대로 넣음.
실제 결과(`[1, 3, 4, 0, 2]`)가 기대(`[2, 4, 5, 1, 3]`)보다 1씩 작아 — 
즉시 "아, 인덱스 +1 안 했구나" 깨달음.
