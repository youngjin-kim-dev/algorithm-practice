# 문자열 출력하기

[프로그래머스 문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/181952)

## 문제 요약
문자열 str을 입력받아 그대로 출력.

## 풀이
\`\`\`python
str = input()
print(str)
\`\`\`

## 막힌 부분

### 시도 — `input('HelloWorld!')`
처음에 `input()` 안에 출력할 문자열을 넣음:
\`\`\`python
str = input('HelloWorld!')
\`\`\`

결과: **시간 초과**.

원인: `input(안내문)`은 — 안내문을 출력 후 **사용자 입력을 기다림**.
채점 시스템이 입력을 안 줘서 무한 대기.

### 핵심 깨달음
- `input()` 안에 들어가는 건 — **안내 문구** (출력할 값 아님)
- 실제 입력은 — 사용자(또는 채점 시스템)가 줌

## 배운 점

### `input()` 함수의 의미
\`\`\`python
값 = input()              # 입력만 받기
값 = input("안내: ")       # "안내: " 출력 후 입력 받기
\`\`\`

`input()` — 사용자로부터 **입력을 받는** 함수.
괄호 안 문자열은 — 안내 문구(prompt)지 출력값 아님.

### 표준 입출력 패턴
\`\`\`python
값 = input()    # 입력
print(값)       # 출력
\`\`\`

알고리즘 문제에서 — 가장 기본 패턴.
- 채점 시스템이 입력을 줌 (다양한 케이스)
- 본인 코드는 그 입력 처리 후 출력

### `input()` vs `print()` 구분
| 함수 | 동작 |
|---|---|
| `input()` | 입력 받기 (반환값 = 입력 문자열) |
| `print()` | 출력 |

이번 시행착오 — 두 함수의 역할 헷갈림.

### `str` 변수명 주의 (참고)
`str`은 — Python의 **내장 함수 이름**(문자열 변환).
\`\`\`python
str(123)    # "123" (숫자 → 문자열)
\`\`\`

실무에선 — 변수명으로 `str` 사용하면 내장 함수 가려서 버그 가능.
다른 이름(예: `s`, `text`) 사용 권장. 다만 문제에서 변수명을 `str`로 줬으면 그대로 사용.

## 입출력 흐름
\`\`\`
입력: "HelloWorld!"
처리: str = "HelloWorld!"
출력: HelloWorld!
\`\`\`

\`\`\`
입력: "Python"
처리: str = "Python"
출력: Python
\`\`\`

다양한 입력 — 본인 코드는 모두 처리.
