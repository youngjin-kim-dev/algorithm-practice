[프로그래머스 문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/340204?language=python3)

## 문제 요약
환자 코드의 마지막 4글자에 따라 병과를 출력하는 코드의 빈칸을 채우는 문제.

## 풀이
\`\`\`python
code = input()
last_four_words = code[-4:]

if last_four_words == "_eye":
    print("Ophthalmologyc")
elif last_four_words == "head":
    print("Neurosurgery")
elif last_four_words == "infl":
    print("Orthopedics")
elif last_four_words == "skin":
    print("Dermatology")
else:
    print("direct recommendation")
\`\`\`

## 배운 점

### 1. `elif`는 `else if`의 줄임
다른 언어(C, Java 등)의 `else if`와 같은 역할.
- `if` — 첫 조건 (필수)
- `elif` — 추가 조건 (몇 개든 사용 가능)
- `else` — 위 모두 아닐 때 (조건 없음)

\`\`\`python
if 조건1:
    실행1
elif 조건2:
    실행2
elif 조건3:
    실행3
else:
    실행4
\`\`\`

### 2. 슬라이싱 `[-4:]`
Python의 슬라이싱 문법 — 문자열·리스트의 일부를 잘라내는 방법.

\`\`\`python
code = "abc_eye"
code[-4:]    # "_eye" (뒤에서 4글자)
\`\`\`

- `[시작:끝]` — 시작 인덱스부터 끝 인덱스 직전까지
- 음수 인덱스 — 뒤에서부터 셈 (-1이 마지막)
- `[-4:]` — 뒤에서 4번째부터 끝까지

**활용 예시**:
\`\`\`python
"hello"[0:3]      # "hel" (앞 3글자)
"hello"[-3:]      # "llo" (뒤 3글자)
"hello"[2:]       # "llo" (인덱스 2부터 끝)
"hello"[:3]       # "hel" (처음부터 인덱스 3 직전)
\`\`\`

문자열뿐 아니라 리스트에도 동일하게 사용 가능:
\`\`\`python
[1, 2, 3, 4, 5][-2:]    # [4, 5]
\`\`\`
