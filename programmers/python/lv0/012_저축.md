# 빈칸 채우기 - 저축

[프로그래머스 문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/250130)

## 문제 요약
목표 100만 원 모으는데 걸리는 개월 수 출력.
- 첫 달: start만큼 저축
- 70만 원 미만: 매월 before씩 저축
- 70만 원 이상 ~ 100만 원 미만: 매월 after씩 저축

빈칸 3개 채우는 빈칸 채우기 문제.

## 풀이
\`\`\`python
start = int(input())
before = int(input())
after = int(input())

money = start
month = 1
while money < 70:
    money += before
    month += 1
while money < 100:
    money += after
    month += 1

print(month)
\`\`\`

**빈칸 답**:
1. `before` (70만 원 전까지의 월 저축액)
2. `money` (두 번째 while의 조건 변수)
3. `money += after` (70만 원 이후의 월 저축액)

## 막힌 부분
한 번에 통과.

## 배운 점

### 두 단계 while 루프 패턴
조건이 단계별로 바뀌는 경우 — while 두 번 사용.
\`\`\`python
while money < 70:        # 1단계: 70만 원까지
    money += before
    month += 1
while money < 100:       # 2단계: 100만 원까지
    money += after
    month += 1
\`\`\`

같은 변수(money, month)를 공유하면서 — 단계별로 다른 증가율 적용.

### 두 while 루프 사이 변수 공유
첫 while 끝나면 — money는 70 이상이 되어 있음.
그 상태에서 — 두 번째 while이 자연스럽게 이어받음.

### 조건이 단계별로 변하는 패턴
이번 문제처럼 — "조건 A까지는 X, 그 이후는 Y" 패턴은:
- if문 안에 분기로도 가능 (한 while 안에서)
- while 두 개로도 가능 (단계별 분리)
