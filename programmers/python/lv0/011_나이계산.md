# 빈칸 채우기 - 나이 계산

[프로그래머스 문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/250131)

## 문제 요약
출생 연도(year)와 나이 종류(age_type)가 주어질 때 — 2030년 기준 나이 출력.
- age_type = "Korea" → 한국식 (현재 - 출생 + 1)
- age_type = "Year" → 연 나이 (현재 - 출생)

## 풀이
\`\`\`python
year = int(input())
age_type = input()

if age_type == "Korea":
    answer = 2030 - year + 1
elif age_type == "Year":
    answer = 2030 - year

print(answer)
\`\`\`

## 막힌 부분
"2030년에 몇 살인지" 부분을 — "현재 연도에 몇 살인지"로 잘못 읽음.
실제 코드 작성 시 2026 (실제 현재 연도) 사용 → 출력 예시(31)와 불일치.

문제는 — **2030년 고정값**으로 명시되어 있었음.

### 검증
- year=2000, Korea → 출력 예시 31
- 2030 - 2000 + 1 = 31 ✓
- 2026 - 2000 + 1 = 27 ✗

입출력 예시로 역산하면 — 2030이 정답임을 확인 가능.

## 배운 점

### 문제 정독의 중요성
"현재 연도"라고 가정하지 말고 — 문제에 명시된 값 사용.
"2030년"이라는 구체 숫자가 — 답의 핵심이었음.

## 추가 학습 — 현재 연도 동적으로 가져오기
이 문제는 2030 고정이지만, 실무에서는 — 현재 연도 동적 추출이 자주 필요.

\`\`\`python
from datetime import datetime

current_year = datetime.now().year
print(current_year)    # 실행 시점의 연도
\`\`\`

활용 예 (이 문제를 동적으로 만들면):
\`\`\`python
from datetime import datetime

year = int(input())
age_type = input()
current_year = datetime.now().year

if age_type == "Korea":
    answer = current_year - year + 1
elif age_type == "Year":
    answer = current_year - year

print(answer)
\`\`\`

다만 이 문제는 — 빈칸 채우기라 import 추가 못 함. 2030 고정값 사용.
