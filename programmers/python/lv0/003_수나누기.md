# 디버깅 — 수 나누기

[프로그래머스 문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/340205)

## 문제 요약
2자리 이상의 정수 number를 2자리씩 자른 뒤, 자른 수를 모두 더한 합 출력.
**1줄만 수정**해서 버그를 고치는 디버깅 문제.

## 원본 코드 (버그 있음)
\`\`\`python
number = int(input())
answer = 0

for i in range(1):
    answer += number % 100
    number //= 100

print(answer)
\`\`\`

`range(1)` — 1번만 반복 → 마지막 두 자리만 더해지고 종료.

## 풀이
\`\`\`python
for i in range(len(str(number)) // 2):
    answer += number % 100
    number //= 100
\`\`\`

`range(1)` → `range(len(str(number)) // 2)`로 변경.
자릿수의 절반만큼 반복 (4859는 4자리 → 2번 반복).

## 막힌 부분
한 줄 안에 모르는 문법이 4가지나 있어서 막힘.

### 1. `range(1)`을 무한 반복으로 오해
`while(1)`처럼 — "1 = True니까 무한 반복"이라고 생각.

실제로는:
- `while(1)` — 조건이 True인 동안 무한 반복
- `range(1)` — 0부터 1 미만까지 (즉 [0]), **딱 1번만 반복**

`while`과 `range`는 완전히 다른 동작.

### 2. `//=` 연산자 모름
- `//` — 정수 나눗셈 (몫만)
- `//=` — 정수 나눗셈 후 자기 자신에 대입
- `number //= 100` ≡ `number = number // 100`

### 3. `len()` 함수 모름
객체의 길이·개수 구하는 내장 함수.
- 문자열 → 글자 수
- 리스트 → 원소 개수

### 4. `str()` 함수와 형변환 모름
숫자를 문자열로 변환. 숫자 자체에는 "길이" 개념 없어서 — 자릿수 구하려면 문자열로 바꿔야 함.

### 5. 괄호 위치 실수 (시행착오)
처음엔 `range(len(str(number) // 2))`로 작성 → 에러:
\`\`\`
TypeError: unsupported operand type(s) for //: 'str' and 'int'
\`\`\`

원인: `str(number) // 2` — 문자열을 정수로 나누려 함.
해결: `range(len(str(number)) // 2)` — 괄호 위치 변경, len 결과를 2로 나눠야 함.

## 배운 점

### range 함수
\`\`\`python
range(5)        # 0, 1, 2, 3, 4 (5번 반복)
range(1, 5)     # 1, 2, 3, 4 (4번 반복)
range(0, 10, 2) # 0, 2, 4, 6, 8 (스텝 2)
\`\`\`
- `range(N)` — N번 반복
- `while True` — 조건으로 끝낼 때까지 무한 반복

### len() 함수
\`\`\`python
len("4859")        # 4 (문자열 길이)
len([1, 2, 3])     # 3 (리스트 원소 개수)
\`\`\`
**주의**: 숫자에는 len 못 씀 → str()로 변환 후 사용.

### str() — 형변환
\`\`\`python
str(4859)         # "4859"
int("4859")       # 4859
float("3.14")     # 3.14
\`\`\`
같은 데이터라도 자료형 다르면 가능한 연산이 다름.

### 자릿수 구하는 패턴
\`\`\`python
len(str(number))   # 숫자 → 문자열 → 길이 = 자릿수
\`\`\`
자주 쓰이는 패턴이라 외워두기.

### 자리수 분리 패턴 (% 와 //)
\`\`\`python
4859 % 100 = 59    # 마지막 두 자리
4859 // 100 = 48   # 마지막 두 자리 제거
\`\`\`

### 에러 메시지 읽기
\`TypeError: unsupported operand type(s) for //: 'str' and 'int'\`
- TypeError — 자료형 에러
- // 연산자가 str과 int 사이에서 안 됨
- 어떤 연산이 잘못됐는지, 어떤 자료형이 문제인지 알려줌

## 풀이 흐름 시뮬레이션
\`\`\`python
number = 4859

# 1회: 4859 % 100 = 59, number = 4859 // 100 = 48
# answer = 0 + 59 = 59

# 2회: 48 % 100 = 48, number = 48 // 100 = 0
# answer = 59 + 48 = 107

# 결과: 107
\`\`\`

## 다른 풀이 방법 비교

### 풀이 1: range로 자릿수 // 2만큼 반복 (이 문제의 정답)
\`\`\`python
for i in range(len(str(number)) // 2):
    answer += number % 100
    number //= 100
\`\`\`
- "1줄만 수정"이라는 출제 의도에 부합
- for문 구조 유지하고 range만 변경
- 정확히 필요한 횟수만 반복 (효율적)

### 풀이 2: while문
\`\`\`python
while number:
    answer += number % 100
    number //= 100
\`\`\`
- **가장 Python스러운 풀이**
- `while number:` — number가 0이 아닌 동안 반복 (Python에서 0은 False)
- 자릿수 계산 불필요, number가 0 되면 자동 종료
- 실무·일반 알고리즘 문제에선 이 방식이 더 깔끔
- 다만 — 이 디버깅 문제의 "1줄 수정 (구조 유지)" 의도엔 맞지 않음

### 풀이 3: range로 자릿수만큼 반복
\`\`\`python
for i in range(len(str(number))):
    answer += number % 100
    number //= 100
\`\`\`
- 통과는 함 (number가 0이 되어도 % 100 = 0이라 합에 영향 없음)
- 다만 — 불필요한 반복 (효율 떨어짐)
- 10자리 숫자면 — 5번이면 끝날 일을 10번 돌림

## 풀이 비교 표

| 풀이 | 출제 의도 | 효율성 | 코드 간결성 |
|---|---|---|---|
| 풀이 1 (range // 2) | 부합 ✓ | 좋음 | 보통 |
| 풀이 2 (while) | 부합 안 함 (구조 변경) | 좋음 | 좋음 |
| 풀이 3 (range 자릿수) | 부합 | 떨어짐 | 보통 |

## 출제 의도 정리
"디버깅 — 1줄만 수정"이라는 조건 → **풀이 1이 정답**.
원본 for문 구조 유지하면서 `range(1)`만 적절히 수정.

다만 실무·일반 알고리즘에선 — `while number:` 풀이가 더 Python스럽고 표준.
디버깅 문제의 의도(구조 유지)와 실무 베스트 프랙티스(while 사용)가 다를 수 있음.

## 한 줄 학습 요약
이 한 문제에서 학습한 핵심 6가지:
1. `range()` — 반복 횟수 지정 (while과 다름)
2. `//=` — 정수 나눗셈 대입
3. `len()` — 길이 구하기
4. `str()` — 자료형 변환
5. 함수 중첩 시 괄호 위치 (`len(str(x)) // 2` vs `len(str(x) // 2)`)
6. 에러 메시지 읽기 (TypeError 해석)
