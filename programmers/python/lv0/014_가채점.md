# 디버깅 - 가채점

[프로그래머스 문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/250128)

## 문제 요약
- `numbers` — 문의하려는 학생들의 번호 (예: [1, 2, 3])
- `our_score` — 그 학생들이 가채점한 점수 (예: [80, 90, 70])
- `score_list` — 전체 학생의 실제 성적, 1번부터 순서대로 (예: [80, 90, 100, ...])

각 학생의 가채점 점수와 실제 성적이 같으면 "Same", 다르면 "Different".

## 원본 코드 (버그 있음)
\`\`\`python
if numbers[our_score[i]] == score_list[i]:
\`\`\`

문제:
- **좌변**: `numbers[our_score[i]]` — 점수 값을 numbers의 인덱스로 사용. 의미 없음
- **우변**: `score_list[i]` — i번째 인덱스의 점수가 아니라 그 학생의 점수여야 함

## 풀이
\`\`\`python
def solution(numbers, our_score, score_list):
    answer = []
    for i in range(len(numbers)):
        if our_score[i] == score_list[numbers[i] - 1]:
            answer.append("Same")
        else:
            answer.append("Different")
    return answer
\`\`\`

수정: `numbers[our_score[i]] == score_list[i]` → `our_score[i] == score_list[numbers[i] - 1]`

## 막힌 부분

### 좌변 수정 놓침
처음에 우변만 수정 시도 → 실패.
실제로는 — **한 줄 안에서 좌변·우변 둘 다 수정** 필요.

### 정확한 사고법 — 무엇과 무엇을 비교?
"가채점한 점수가 실제 성적과 같은가" — 비교 대상 명확히:
- **가채점한 점수** = `our_score[i]`
- **실제 성적** = `score_list[학생번호 - 1]` = `score_list[numbers[i] - 1]`

비교: `our_score[i] == score_list[numbers[i] - 1]`

### 이 사고법으로 원본 코드 분석
원본의 좌변 `numbers[our_score[i]]`:
- `our_score[i]` = 점수 값 (예: 80)
- `numbers[80]` = numbers 리스트의 80번 인덱스 → 길이 초과로 IndexError 가능
- 점수 값을 인덱스로 사용 — 의미상 완전히 잘못

## 배운 점

### 디버깅 — 한 줄 안에서도 좌변·우변 둘 다 의심
"한 줄 수정"이라고 해서 — 일부분만 고치면 된다는 건 아님.
**한 줄 통째로 잘못된 경우** — 좌변·우변 다 고쳐야 함.

원본 코드를 분석할 때:
1. 우변 의도 파악
2. 좌변 의도 파악
3. 둘 중 어디가 잘못됐는지 (또는 둘 다인지) 판단

### 학생번호 - 1 = 인덱스 패턴
사람의 번호는 1부터, Python 인덱스는 0부터.
\`\`\`python
score_list[학생번호 - 1]    # 1번 학생 = score_list[0]
\`\`\`
