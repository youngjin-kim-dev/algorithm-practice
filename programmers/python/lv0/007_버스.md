# 빈칸 채우기 — 버스

[프로그래머스 문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/340201)

## 문제 요약
영진이가 버스에 탄 순간 빈 좌석 수를 반환.
- `seat` — 버스 총 좌석 수
- `passengers` — 정류장별 승하차 정보 ("On", "Off", "-")
- 영진이가 기다리는 정류장에서 가장 먼저 탑승

주어진 4개 함수 중 적절한 것을 빈칸에 채워서 solution 함수 완성.

## 주어진 함수들
- `func1(num)` — 음수면 0, 양수면 그대로 (음수 보호)
- `func2(num)` — 양수면 0, 음수면 그대로
- `func3(station)` — "Off" 개수 (내리는 사람 수)
- `func4(station)` — "On" 개수 (타는 사람 수)

## 풀이
\`\`\`python
def solution(seat, passengers):
    num_passenger = 0
    for station in passengers:
        num_passenger += func4(station)   # 타는 사람 추가
        num_passenger -= func3(station)   # 내리는 사람 빼기
    answer = seat - func1(num_passenger)  # 빈 좌석 = 좌석 - 인원 (음수 보호)
    return answer
\`\`\`

## 접근 방법
1. 각 정류장 순회하며 승하차 처리
2. `func4` — 타는 사람 더함
3. `func3` — 내리는 사람 뺌
4. 마지막에 `func1`로 음수 보호 (인원이 음수면 0으로)
5. `seat - 인원` = 빈 좌석

## 막힌 부분

### 함수 4개 중 어느 걸 써야 할지 헷갈림
주어진 함수가 4개라 — 어디에 어떤 함수를 매칭할지 처음에 막힘.

해결 — 각 함수의 동작을 먼저 정확히 파악 후, 빈칸의 앞뒤 맥락과 매칭.

### `func1` vs `func2` 선택
인원수는 음수면 안 되니까 — 음수를 0으로 처리하는 함수 필요.
- func1(음수면 0) ✓
- func2(양수면 0) — 의미 안 맞음

## 배운 점

### 함수 정의·호출 구조
\`\`\`python
def func4(station):       # 정의
    ...
    return num

func4(station)            # 호출 (반환값 사용)
\`\`\`

함수는 — 입력(인자) → 처리 → 출력(반환값). 같은 로직 반복하지 않고 재사용.

### 빈칸 채우기 사고법
1. 각 빈칸의 **앞뒤 맥락** 파악
   - `+=` 뒤니까 더할 값 (양수)
   - `-=` 뒤니까 뺄 값 (양수)
2. 주어진 함수들의 **반환값 분석**
   - 어떤 입력에 어떤 출력?
3. 맥락과 반환값 **매칭**

### 보호 로직 패턴
인원수, 개수 같은 값은 음수가 되면 의미 없음.
\`\`\`python
def func1(num):
    if 0 > num:
        return 0
    else:
        return num
\`\`\`
음수일 때 0으로 보정 — 자주 쓰는 보호 패턴.

### 함수 동작 분석 → 의미 파악
함수 이름이 `func1, func2, func3, func4`처럼 의미 없는 이름일 때 — 
**코드 동작을 직접 읽어서 의미 파악**해야 함.

- func3: `"Off"` 카운트 → "내리는 사람 수"
- func4: `"On"` 카운트 → "타는 사람 수"

이름이 아니라 **로직**으로 의미 추론하는 능력이 빈칸 채우기 핵심.

## 풀이 흐름 시뮬레이션
입력:
\`\`\`python
seat = 5
passengers = [
    ["On", "On", "On"],      # 1번: 3명 탐
    ["Off", "On", "-"],       # 2번: 1명 탐, 1명 내림
    ["Off", "-", "-"]         # 3번: 1명 내림
]
\`\`\`

\`\`\`
1번: num_passenger = 0 + 3 - 0 = 3
2번: num_passenger = 3 + 1 - 1 = 3
3번: num_passenger = 3 + 0 - 1 = 2

answer = 5 - func1(2) = 5 - 2 = 3
\`\`\`
빈 좌석 3개. (영진이가 4번 정류장에서 가장 먼저 탑승)
