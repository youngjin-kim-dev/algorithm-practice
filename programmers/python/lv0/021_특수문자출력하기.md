# 특수문자 출력하기

[프로그래머스 문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/181948)

## 문제 요약
특수문자가 포함된 문자열 출력.

**출력**:
\`\`\`
!@#$%^&*(\\'"<>?:;
\`\`\`

출력에 — `\`, `'`, `"` 모두 포함되어 있음. 이스케이프 처리 필요.

## 풀이
\`\`\`python
print('!@#$%^&*(\\\\\\'"<>?:;')
\`\`\`

분해:
- `\\\\` → 출력 시 `\` (백슬래시)
- `\\'` → 출력 시 `'` (작은따옴표)
- `"` → 그대로 (작은따옴표로 감쌌으니까)

## 막힌 부분
출력에 — 작은따옴표와 큰따옴표 둘 다 포함. 문자열 감싸는 따옴표로 무엇을 쓸지 헷갈림.

핵심 깨달음: **이스케이프 문자**(`\\`) 사용으로 — 따옴표 안에 같은 따옴표 포함 가능.

## 배운 점

### 따옴표로 문자열 감싸기
Python 문자열은 — `'...'` 또는 `"..."`로 감쌈.

\`\`\`python
'hello'    # OK
"hello"    # OK
\`\`\`

### 따옴표 안에 같은 따옴표 — 이스케이프 필요
\`\`\`python
'It's mine'     # 에러! 작은따옴표 안에 작은따옴표
'It\\'s mine'    # OK (이스케이프)
"It's mine"     # OK (큰따옴표로 감싸면 작은따옴표 자유)
\`\`\`

### 이스케이프 문자 (`\\`)
백슬래시 `\\` — 다음 문자를 **특수하게 처리**.

| 이스케이프 | 의미 |
|---|---|
| `\\\\` | 백슬래시 `\` |
| `\\'` | 작은따옴표 `'` |
| `\\"` | 큰따옴표 `"` |
| `\\n` | 줄바꿈 |
| `\\t` | 탭 |

### 따옴표 선택 전략
출력 안에 어떤 따옴표가 있는지 보고 선택:

| 출력에 포함된 것 | 추천 |
|---|---|
| `'`만 | `"..."`로 감싸기 |
| `"`만 | `'...'`로 감싸기 |
| 둘 다 | 이스케이프 또는 삼중 따옴표 |

이번 문제 — 둘 다 포함이라 — 이스케이프 사용.

### 삼중 따옴표 (참고)
\`\`\`python
print('''!@#$%^&*(\\\\'"<>?:;''')
\`\`\`

삼중 따옴표(`'''` 또는 `"""`) 안에 — 작은/큰 따옴표 둘 다 자유롭게.
다만 — `\\` 자체는 여전히 이스케이프 필요.

## 다른 풀이 — 큰따옴표 사용
\`\`\`python
print("!@#$%^&*(\\\\'\\"<>?:;")
\`\`\`

분해:
- `\\\\` → `\`
- `'` → 그대로 (큰따옴표로 감쌌으니까)
- `\\"` → `"`

작은따옴표 풀이와 — **결과 동일**. 가독성 따라 선택.

## 다른 풀이 — 삼중 따옴표
\`\`\`python
print("""!@#$%^&*(\\\\'"<>?:;""")
\`\`\`

가장 깔끔. 작은/큰 따옴표 둘 다 그대로 OK. 백슬래시만 이스케이프.

## 입출력 흐름
\`\`\`
print('!@#$%^&*(\\\\\\'"<>?:;')

Python 해석:
  '!@#$%^&*('    → !@#$%^&*(
  \\\\            → \
  \\'            → '
  "<>?:;'        → "<>?:;

최종 출력: !@#$%^&*(\\'"<>?:;
\`\`\`
